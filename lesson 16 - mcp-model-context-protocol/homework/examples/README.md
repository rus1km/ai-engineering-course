# Examples

Сюди покладіть 3 скріншоти реальних діалогів із сервером `notes`
у Claude Desktop (див. сценарії «3 приклади діалогів» у головному README):

1. `01-add-note.png`     — створення нотаток (`add_note`, required + optional args)
2. `02-search-notes.png` — пошук і фільтр за тегом (`search_notes`)
3. `03-stats-delete.png` — читання resource `notes://stats` + `delete_note`

Як зробити: відкрийте діалог у Claude Desktop, виконайте сценарій,
зробіть скріншот (macOS: Cmd+Shift+4) і збережіть у цю папку під вказаними іменами.
